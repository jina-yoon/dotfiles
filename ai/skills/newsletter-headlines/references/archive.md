# Archive: every past newsletter title + subtitle

Every issue of PostHog's newsletter (Product for Engineers, renamed **build mode** in July 2026), newest first. Format is:

`Date — Title — Subtitle`

Read this file when you want to (a) check a proposed title isn't a near-duplicate of something already published, (b) see how a given format has been used before, or (c) pull real examples to calibrate voice. The `patterns.md` file in this same folder slices the same data by format if that's what you need.

Note on the "N things we've learned" format: it has been used roughly annually and always with a real, specific number tied to a real body of experience (32 things from scaling 11→150 people, 43 things from 30k applications). It reads as lazy when the number is arbitrary.
